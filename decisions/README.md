# Decisions

Answers "why did we decide that?" six months from now. Template: `_templates/decision.md`. Filename: `YYYY-MM-DD_short-name.md`.

**Log a decision when** it would be costly to reverse, more than one option was seriously considered, someone outside the room will ask "why?", or it changes scope, timeline or a standing convention. **Timeline and scope changes are always logged.** They're usually agreed verbally and never written down.

Small in-the-moment calls belong in the meeting note, not here.
