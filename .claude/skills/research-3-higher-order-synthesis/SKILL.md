# Stage 3: Higher-order synthesis

**Input:** the stage-2 CISD (`research/synthesis/…_cisd.md`). **Output:** `research/synthesis/YYYY-MM-DD_higher-order-synthesis.md`, following `template.md` in this folder.

## Instructions

1. **Work only from the CISD.** Don't pull from memory or go back to the raw transcripts for new claims. If you need a better quote, take it from the stage-1 file the CISD cites.
2. **Every item traces back.** Insights → named CISD themes. Opportunities → insights. Strategic implications → insights or opportunities. Anything that can't be traced goes in Open Questions instead.
3. **Insight ≠ finding.** An insight explains *why* something is true and what it means. Format: "[Subject] [does / needs / believes] [X] because [driver]. This means [implication]."
4. Label each insight `Pattern-driven` (backed by several themes) or `Hypothesis-driven` (interpretation on thin evidence). Both are allowed; don't overclaim.
5. **HMWs:** mostly `Balanced` scope. Nothing leading ("…add a dashboard?") and nothing hopelessly vague.
6. **Tensions:** carry forward every one the CISD flagged. Don't smooth them away; they're often the most productive design territory.
7. **Minority voices** from the CISD must appear in at least one insight, tension or open question.
8. Aim for 3–5 insights, 3+ opportunities, 5–7 HMWs and 2+ tensions. Fewer is fine if the evidence is thin; say so.
9. **Fill in the Confidence Assessment honestly.** If three or more checks fail, stop and tell the user to revise before running stage 4 or 5. Note that "second researcher reviewed" needs a human.
