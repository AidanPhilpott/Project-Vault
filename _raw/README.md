# _raw

Drop raw originals here (transcripts, PDFs, decks, spreadsheets, exports) for `pos-intake` to read.

Everything in this folder except this README is git-ignored. The synthesized note in `meetings/` or `context/` is the artifact; it cites the original by filename. Don't put anything here that the "Does NOT go in this folder" list in `CLAUDE.md` rules out, even locally.
